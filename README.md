## 👩‍💻 About the Internship

This repository contains the projects developed as part of my **CodeAlpha Full Stack Development Internship**.

The internship provided hands-on experience in building modern web applications using frontend and backend technologies, working with databases and APIs, implementing authentication, and following practical software development workflows.

## 🚀 Projects

### 🛒 CodeAlpha Ecommerce Store

A full-stack e-commerce web application designed to provide users with a modern online shopping experience.

**Technologies:**
- React.js
- JavaScript
- HTML5
- CSS3
- Node.js
- Express.js
- MongoDB
- Mongoose

📁 Project: `CodeAlpha_EcommerceStore`

### 🌐 CodeAlpha Social Media Platform

A full-stack social media platform that allows users to create posts, interact with content, follow other users, explore profiles, and manage their social connections.

**Technologies:**
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST APIs

📁 Project: `CodeAlpha_SocialMediaPlatform`
